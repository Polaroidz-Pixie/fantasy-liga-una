# Emblemas das equipas

Para usar o emblema de uma equipa, põe aqui o ficheiro (PNG, SVG, WEBP ou JPG, de preferência quadrado
e com fundo transparente) e acrescenta-o a `index.json`, com a sigla usada na app:

```json
{ "BEN": "BEN.png", "SCP": "SCP.png" }
```

Siglas: BEN Benfica · SCP Sporting · VSC Vitória SC · LEI Leixões · AAE Académica de Espinho ·
SCE Sporting de Espinho · SMA São Mamede · CMA Castêlo da Maia · KAI Kairós · MAD Madalena ·
GON Ala Gondomar · STI Santo Tirso · OEI Oeiras.

Equipas sem ficheiro continuam a mostrar o emblema com a sigla.
Os emblemas oficiais são marcas dos clubes: confirma que os podes usar antes de os publicar.
